# Clinical Trial Data Validation and Analysis Project

## Project Overview
This project demonstrates a simulated Clinical Data Management (CDM) workflow using Microsoft Excel.

## Objectives
- Data entry and validation
- Data cleaning
- Duplicate identification
- Missing value checking
- Query generation
- Final cleaned dataset preparation

## Files Included
- Clinical_Trial_Data.xlsx – Raw clinical trial dataset
- Cleaned_Clinical_Data.xlsx – Cleaned dataset
- Query_Report.xlsx – Data discrepancy report
- CDM_Project_Workbook.xlsx – Complete project workbook

## Skills Demonstrated
- Clinical Data Management (CDM)
- Data Validation
- Data Cleaning
- Microsoft Excel
- Query Management
- Documentation
